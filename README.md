# Linux Administration Labs

**Hands-on Linux system administration exercises from a university course, with my written solutions.**

The assignments (in Russian) cover the core skills of a junior Linux administrator:

| # | Topic | Covers |
|---|---|---|
| 1 | Working with files | stdin / stdout / stderr, redirection (`>`, `>>`, `<`, `2>`), pipes, text tools |
| 2 | User management | users and groups, `useradd` / `usermod`, login shells, restricting access |
| 3 | File systems | file system types, creating and mounting file systems |
| 4 | Bash | shebang, `set -euo pipefail`, automating file tasks with scripts |
| 5 | systemd | services, writing custom unit files, autostart |
| 7 | SSH | `sshd` configuration, ports, root login, key auth, `known_hosts` |
| 8 | Samba | file sharing with Windows clients |
| 9 | Firewall | iptables rules without losing SSH access |
| — | Network | interfaces, addressing, diagnostics |

## My contributions

I wrote detailed solutions, with commands, explanations and examples, for:

- [`1-Work whith files/task2.md`](1-Work%20whith%20files/task2.md): I/O streams and redirection
- [`2-User manage/task2.md`](2-User%20manage/task2.md): user and group administration
