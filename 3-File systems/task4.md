Что такое RAID

RAID (Redundant Array of Independent Disks) — это технология объединения нескольких физических жёстких дисков или SSD в один логический массив. Для операционной системы такой массив выглядит как единое устройство хранения данных.

Основные цели использования RAID:

увеличение производительности операций чтения и записи;

повышение надёжности хранения данных;

защита от потери информации при выходе из строя одного или нескольких дисков.

Важно понимать, что RAID не является резервным копированием (backup). RAID защищает от аппаратных отказов дисков, но не от ошибок пользователя, вирусов или повреждения файловой системы.
Существует несколько уровней RAID, каждый из которых решает разные задачи.

RAID 0 (Striping)

использует минимум два диска;

данные разбиваются на блоки и записываются поочерёдно на разные диски;

обеспечивает высокую скорость работы;

не имеет отказоустойчивости — при выходе из строя одного диска теряются все данные массива.

RAID 1 (Mirroring)

использует минимум два диска;

данные полностью дублируются на каждом диске;

обеспечивает высокую надёжность;

полезный объём равен объёму одного диска.

RAID 5 и RAID 6

используют механизм чётности;

требуют минимум 3 (RAID 5) или 4 (RAID 6) диска;

обеспечивают баланс между надёжностью и эффективным использованием пространства.

RAID 10

комбинация RAID 0 и RAID 1;

требует минимум 4 диска;

сочетает высокую скорость и отказоустойчивость.

В рамках данной работы используются RAID 0 и RAID 1, так как они являются базовыми и наглядно демонстрируют различия между скоростью и надёжностью.
Подготовка виртуальной машины

Для выполнения работы в виртуальную машину добавляются два дополнительных диска.
После запуска системы необходимо убедиться, что они распознаются ОС:
```
lsblk
```

Как правило, новые диски отображаются как /dev/sdb и /dev/sdc.

Форматирование и подготовка дисков

Перед созданием RAID на каждом диске создаётся отдельный раздел, предназначенный для участия в массиве.
Разделы помечаются специальным типом Linux RAID.

После разметки система должна видеть:
```
/dev/sdb1

/dev/sdc1
```
Создание RAID 0

RAID 0 создаётся путём объединения двух разделов в один массив с чередованием данных:
```
sudo mdadm --create /dev/md0 \
--level=0 \
--raid-devices=2 \
/dev/sdb1 /dev/sdc1
```

После создания массив отображается как устройство /dev/md0.

Форматирование RAID 0 в ext4

Несмотря на то что исходные диски могли быть пустыми, форматируется именно RAID-устройство, а не отдельные диски:
```
sudo mkfs.ext4 /dev/md0
```

Затем массив монтируется в файловую систему:
```
sudo mount /dev/md0 /mnt/raid0
```
Проверка работоспособности RAID 0

Работоспособность массива проверяется:

наличием устройства /dev/md0;

выводом команды:
```
cat /proc/mdstat
```

успешной записью и чтением файлов.

При записи данных используется одновременно оба диска, что обеспечивает высокую скорость.

Удаление RAID 0

Перед удалением массива его необходимо корректно остановить:

размонтировать файловую систему;

остановить RAID-устройство;

удалить метаданные RAID с дисков.

Это предотвращает ошибки при повторном использовании дисков.

Создание RAID 1

RAID 1 создаётся аналогичным образом, но с другим уровнем:
```
sudo mdadm --create /dev/md1 \
--level=1 \
--raid-devices=2 \
/dev/sdb1 /dev/sdc1
```

В этом случае данные полностью копируются на оба диска.

Форматирование и проверка RAID 1

RAID 1 также форматируется в ext4 и монтируется в каталог, например /mnt/raid1.
При записи файлов данные автоматически дублируются на каждом диске массива.

Даже при выходе из строя одного диска информация остаётся доступной.
Файловые системы с поддержкой RAID без стороннего ПО

Существуют файловые системы, которые реализуют RAID внутри себя, без использования mdadm:

Btrfs

поддерживает RAID 0, 1 и 10;

имеет контроль целостности данных;

позволяет динамически изменять массив.

ZFS

использует RAID-Z;

обеспечивает высокий уровень надёжности;

широко применяется на серверах.

В этих файловых системах RAID — часть самой архитектуры.

RAID во время установки системы

RAID-массив можно создать непосредственно во время установки Linux:

через ручную разметку дисков;

с использованием встроенного mdadm;

возможна установка системы на RAID 1 (включая /boot).

Это позволяет получить отказоустойчивую систему сразу после установки, без дополнительной настройки.
