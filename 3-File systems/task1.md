# Файловые системы (Linux)

## 1. Какие файловые системы вы знаете
FAT32, exFAT, NTFS, ext2, ext3, ext4, XFS, Btrfs, ZFS, ISO9660, tmpfs, procfs, sysfs, CIFS, NFS.

## 2. Классификация файловых систем и отличия
- **Локальные** — работают с физическими носителями (ext4, XFS, NTFS)
- **Сетевые** — доступ по сети (NFS, CIFS)
- **Виртуальные** — не хранят данные на диске, отображают состояние системы (procfs, sysfs, tmpfs)
- **Журналируемые** — ведут журнал изменений (ext4, XFS, Btrfs)
- **Нежурналируемые** — без журнала (ext2, FAT32)

Отличия: поддержка журналирования, отказоустойчивость, производительность, масштабируемость, назначение.

## 3. Файловые системы, используемые в Linux
ext4, XFS, Btrfs, ext3, ext2, tmpfs, procfs, sysfs, CIFS, NFS.

## 4. Создание файловой системы на диске
```bash
sudo mkfs.ext4 /dev/sdb1
```
Подключение диска и монтирование

Монтирование — это подключение файловой системы к каталогу.
```
sudo mkdir /mnt/disk
sudo mount /dev/sdb1 /mnt/disk
```
6. procfs, cifs, tmpfs, sysfs — особенности

procfs — информация о процессах и системе

sysfs — информация об устройствах и драйверах

tmpfs — файловая система в оперативной памяти

cifs — доступ к сетевым ресурсам Windows (SMB)

Вывод каталогов монтирования:
```
mount | grep -E "proc|sys|tmp|cifs"
```
7. Получение информации о системе с помощью cat

Информация о процессоре:
```
cat /proc/cpuinfo
```

Состояние памяти:
```
cat /proc/meminfo
```
