Какие файловые системы используются в Linux?

В Linux используются следующие файловые системы:

ext2 — простая файловая система без журналирования

ext3 — файловая система с журналированием

ext4 — основная и самая распространённая файловая система Linux

XFS — производительная файловая система, часто используется на серверах

Btrfs — современная файловая система с расширенными возможностями

procfs — виртуальная файловая система для информации о процессах

sysfs — виртуальная файловая система для информации об устройствах

tmpfs — файловая система в оперативной памяти

cifs, nfs — сетевые файловые системы

Как можно классифицировать файловые системы в Linux?

Файловые системы в Linux можно классифицировать:

1) По типу хранения данных

Дисковые — данные хранятся на физическом носителе
(ext4, xfs, btrfs)

Виртуальные — данные не хранятся на диске
(procfs, sysfs, tmpfs)

2) По назначению

Локальные — работают с локальными устройствами

Сетевые — используются для доступа к ресурсам по сети (cifs, nfs)

3) По наличию журналирования

Без журналирования — ext2

С журналированием — ext3, ext4, xfs, btrfs

В чём отличия файловых систем?

Файловые системы отличаются:

способом хранения данных;

надёжностью;

производительностью;

наличием журналирования;

назначением (локальные, виртуальные, сетевые).

Как создать файловую систему в Linux?

Файловая система создаётся командой mkfs.

Пример создания файловой системы ext4:
```
sudo mkfs.ext4 /dev/sdb1
```
Как подключить диск в Linux? Что такое монтирование?

Монтирование — это подключение файловой системы к каталогу в общем дереве Linux.

Пример:
```
sudo mkdir /mnt/disk
sudo mount /dev/sdb1 /mnt/disk
```
Файловые системы procfs, sysfs, tmpfs, cifs. Особенности
procfs

виртуальная файловая система

содержит информацию о процессах и системе

примонтирована в /proc

sysfs

виртуальная файловая система

содержит информацию об устройствах и драйверах

примонтирована в /sys

tmpfs

файловая система в оперативной памяти

данные удаляются после перезагрузки

используется для временных файлов (/tmp, /run)

cifs

сетевая файловая система

используется для подключения сетевых ресурсов

К каким каталогам примонтированы файловые системы?

Просмотр примонтированных файловых систем:

df -T


Или:

mount

Как получить информацию о системе, используя только cat?
Информация о процессоре
```
cat /proc/cpuinfo
```

Информация о состоянии памяти
cat /proc/meminfo
