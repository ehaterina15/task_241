
# =========================
# Запрет входа пользователю
# =========================

# 1. Запретить пользователю user1 вход в систему
sudo usermod -s /usr/sbin/nologin user1

# Альтернативный способ — блокировка учётной записи
sudo passwd -l user1

# =========================
# Пояснения
# =========================

# Как это сделано:
# - usermod -s /usr/sbin/nologin
#   Меняет оболочку пользователя на nologin, вход в систему запрещён
#
# - passwd -l
#   Блокирует пароль пользователя

# Другие способы запрета входа:
# 1) Заблокировать пользователя
# sudo usermod -L user1
#
# 2) Установить /bin/false как оболочку
# sudo usermod -s /bin/false user1
#
# 3) Удалить пароль
# sudo passwd -d user1
#
# 4) Ограничить вход через PAM или SSH
# (например, через /etc/ssh/sshd_config)

# Можно ли создать пользователей с одинаковыми username?
# Нет. В Linux username должен быть уникальным.
