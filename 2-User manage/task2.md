Запрет входа в систему для пользователя user1
 изменение оболочки

Пользователю назначается оболочка, не позволяющая вход в систему.
```
sudo usermod -s /usr/sbin/nologin user1
```

Проверка:
```
getent passwd user1
```

Результат:
```
user1:x:1001:1001::/home/user1:/usr/sbin/nologin
```

➡️ Пользователь user1 не может войти в систему, но его учётная запись и файлы сохраняются.
 Как именно был запрещён вход

В Linux вход в систему возможен только при наличии допустимой оболочки
(bash, sh, zsh и т.д.).

Назначение оболочки:
```
/usr/sbin/nologin
```
или
``` /bin/false
```

приводит к тому, что:

аутентификация возможна

интерактивный вход невозможен

 Другие способы запрета входа пользователя
1) Блокировка пароля
```
sudo passwd -l user1

```
Разблокировка:
```
sudo passwd -u user1
```
Истечение срока действия учётной записи
 ```
sudo chage -E 0 user1
```

Проверка:
```
sudo chage -l user1
```
3) Использование файла /etc/nologin
```
sudo touch /etc/nologin

```
⚠️ Запрещает вход всем пользователям, кроме root.

Можно ли создать пользователей с одинаковыми username?

Нет.

В Linux:

каждый пользователь имеет уникальное имя

username — это ключ в /etc/passwd

Попытка создать пользователя с существующим именем:
```
sudo useradd user1
```

Результат:
```
useradd: user 'user1' already exists
```

✅ Однако:

UID тоже должен быть уникальным

одинаковые display name (GECOS) возможны

одинаковые домашние каталоги возможны, но не рекомендуются
