# Лабораторная работа №1  
## Работа с файлами в операционной системе Linux

### Цель работы  
Целью данной лабораторной работы является изучение базовых команд операционной системы Linux, предназначенных для работы с файловой системой. В ходе выполнения работы необходимо освоить навыки навигации по каталогам, создания и управления файлами, а также использования стандартных консольных утилит.

---

### Задание  
Выполнить основные операции с файлами и каталогами в Linux, включая:
- навигацию по файловой системе;
- просмотр содержимого директорий;
- создание файлов и каталогов;
- работу со скрытыми файлами;
- копирование, перемещение и переименование файлов;
- сравнение содержимого файлов;
- сортировку данных в файле.


---
### Ход выполнения работы  

В начале работы был выполнен просмотр содержимого текущей директории с использованием команды:
```bash
ls

```
Затем были созданы несколько файлов:
```
touch file1.txt file2.txt file3.txt
```
Для демонстрации работы со скрытыми файлами был создан файл с точкой в начале имени и выполнен просмотр всех файлов:
```
touch .hidden_file
ls -a
```
После этого в созданные файлы была записана текстовая информация:
```
echo "First file" > file1.txt
echo "Second file" > file2.txt
echo "Third file" > file3.txt
```
Далее были созданы каталоги и вложенные подкаталоги:
mkdir -p dirC/subdirC dirD/subdirD
В каталоге dirC был создан файл inside.txt, в который был записан текст:

cd dirC
echo "This is a test text" > inside.txt
cd ..


Созданный файл был перемещён из каталога dirC в каталог dirD:
```
mv dirC/inside.txt dirD/
```

После этого файл был скопирован обратно в текущую директорию и переименован:
```
cp dirD/inside.txt .
mv inside.txt renamed_inside.txt

```
Для сравнения содержимого файлов использовалась команда:
```
diff renamed_inside.txt dirD/inside.txt

```
Отсутствие вывода данной команды означает, что содержимое файлов совпадает.

Для демонстрации сортировки данных был создан файл с числовыми значениями и выполнена сортировка:
```
sort numbers.txt
sort -r numbers.txt
```
