Что за файл options?

Файл options является пользовательским конфигурационным файлом SSH-клиента. Он используется для хранения параметров подключения к удалённому серверу, таких как адрес сервера, имя пользователя и номер порта, и позволяет упростить процесс подключения.

Отредактируйте файл options так, чтобы можно было подключаться не вводя имя пользователя и порт

В файл options были добавлены параметры подключения:

Host myserver
    HostName ternar.io
    User student
    Port 228


Данные настройки позволяют выполнять подключение без указания имени пользователя и порта в командной строке.

Назовите подключение удобным для вас способом

Подключение было названо myserver.
Имя задаётся директивой Host и используется как псевдоним сервера.

Проверьте работоспособность

Проверка работоспособности была выполнена с помощью команды:

ssh -F options myserver
