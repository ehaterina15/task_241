Что такое SSH-ключ́лючи и зачем они нужны?

SSH-ключи — это пара криптографических ключей (приватный и публичный), используемая для аутентификации при подключении по SSH. Они позволяют подключаться к серверу без ввода пароля, повышают уровень безопасности и защищают от перебора паролей и атак типа brute force.

Как их создать?

SSH-ключи создаются с помощью утилиты ssh-keygen, которая генерирует пару ключей на стороне клиента.

Создайте пару публичный/приватный ключ ed25519, где они хранятся?

Пара ключей была создана командой:
```
ssh-keygen -t ed25519
```

В процессе генерации были созданы файлы:

приватный ключ: ~/.ssh/id_ed25519

публичный ключ: ~/.ssh/id_ed25519.pub

Приватный ключ хранится только на стороне клиента и не должен передаваться третьим лицам. Публичный ключ может свободно распространяться.

Скопируйте публичный ключ на ваш сервер, в каком файле он будет храниться?

Публичный ключ был скопирован на сервер командой:
```
ssh-copy-id student@ternar.io -p <228>
```

На сервере публичный ключ сохраняется в файле:
```
~/.ssh/authorized_keys
```

Этот файл содержит список разрешённых публичных ключей для подключения пользователя.

Попробуйте подключиться к серверу, у вас запросили пароль?

После добавления публичного ключа на сервер подключение было выполнено командой:
```
ssh -p <228> student@ternar.io
```

Пароль при подключении не запрашивался, что подтверждает корректную настройку аутентификации по SSH-ключам.
