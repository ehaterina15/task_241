**1. Какой по умолчанию используется порт для подключения?**
По умолчанию для подключения по протоколу SSH используется порт **22**.

---

**2. Можно ли его изменить? Если да, то как?**
Да, порт SSH можно изменить. Для этого необходимо отредактировать конфигурационный файл SSH-сервера и указать новый номер порта в параметре `Port`, после чего перезапустить службу SSH.

---

**3. Какая служба отвечает за обработку запросов на подключение по SSH?**
За обработку запросов на подключение по SSH отвечает служба **sshd** (SSH daemon).

---

**4. Какой файл конфигурации отвечает за его настройку?**
Основной файл конфигурации SSH-сервера —
`/etc/ssh/sshd_config`.

---

**5. Попробуйте подключиться по SSH к предоставленному вам серверу**
Подключение к серверу было выполнено с использованием команды:

```
ssh -p <порт> student@ternar.io
```

Подключение прошло успешно после ввода корректного пароля.

---

**6. Отредактируйте файл настроек на сервере так, чтобы была возможность подключиться к серверу, используя пользователя root**

В файле `/etc/ssh/sshd_config` был изменён параметр:

```
PermitRootLogin yes
```

После внесения изменений служба SSH была перезапущена.

---

**7. Измените количество ошибок ввода пароля перед сбросом соединения, покажите эти изменения**

В файле `/etc/ssh/sshd_config` был изменён параметр:

```
MaxAuthTries 3
```

Это ограничивает количество попыток ввода пароля до трёх перед разрывом соединения.

---

**8. Создайте пользователя ssh-user и попробуйте им подключиться к серверу**

Пользователь был создан командой:

```
sudo useradd -m ssh-user
sudo passwd ssh-user
```

После этого было выполнено успешное подключение по SSH под пользователем `ssh-user`.

---

**9. Ограничьте ему возможность подключения к серверу**

В файле конфигурации SSH был добавлен запрет на подключение пользователя:

```
DenyUsers ssh-user
```

---

**10. Как вы это сделали?**

Ограничение было реализовано путём редактирования файла `/etc/ssh/sshd_config` с использованием директивы `DenyUsers`, после чего служба SSH была перезапущена для применения изменений.

---

**11. Что хранится в файле known_hosts?**

Файл `known_hosts` хранит список известных SSH-хостов и их криптографические ключи. Он используется для проверки подлинности сервера и предотвращения атак типа «man-in-the-middle» при повторных подключениях.
