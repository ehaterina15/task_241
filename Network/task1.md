IP-адрес

IP-адрес — это уникальный сетевой идентификатор узла в сети. В ходе работы на сетевом интерфейсе enp0s3 был назначен IPv4-адрес 10.0.2.15, который используется для сетевого взаимодействия данного узла.

Маска подсети

Маска подсети определяет границы сети и диапазон допустимых адресов. В данной конфигурации используется маска /24, что соответствует подсети 10.0.2.0/24 и позволяет определить принадлежность узла к локальной сети.


Маршруты

Маршруты определяют направление передачи сетевых пакетов. В системе настроен маршрут по умолчанию через шлюз 10.0.2.2 на интерфейсе enp0s3, что обеспечивает доступ к внешним сетям. Также присутствует маршрут локальной сети 10.0.2.0/24.

ARP (Address Resolution Protocol)

ARP — это протокол, используемый для сопоставления IP-адресов с MAC-адресами в локальной сети. В ARP-таблице зафиксировано соответствие IP-адреса шлюза 10.0.2.2 и его MAC-адреса, используемого интерфейсом enp0s3.


DHCP (Dynamic Host Configuration Protocol)

DHCP — протокол автоматической настройки сети. IP-адрес 10.0.2.15, маршрут по умолчанию и другие сетевые параметры были получены динамически по DHCP, без ручной настройки.


DNS (Domain Name System)

DNS — система разрешения доменных имён в IP-адреса. Параметры DNS были получены автоматически по DHCP и используются системой для доступа к сетевым ресурсам по именам.


Протокол синхронизации времени

Для синхронизации системного времени в сетях используется протокол NTP, обеспечивающий согласованное время между устройствами.


Широковещательный запрос

Широковещательный запрос — это передача сетевого пакета всем устройствам локальной сети. В данной сети широковещательные механизмы применяются при работе DHCP и ARP.

Широковещательный адрес

Для подсети 10.0.2.0/24 широковещательным адресом является 10.0.2.255, который используется для рассылки пакетов всем узлам сети.
